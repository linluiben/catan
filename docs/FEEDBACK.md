# Feedback-Bogen nach einer Spielrunde

Am bequemsten füllst du den Bogen als Formular auf GitHub aus: **Issues → New issue → „🎲 Feedback nach einer Spielrunde“**.
Das Formular erscheint, sobald dieser Stand auf dem Standard-Branch `main` liegt.

Für unterwegs oder zum Ausdrucken gibt es hier dieselben Fragen als Markdown. Ersetze `[ ]` durch `[x]` und schreib deine Antworten hinter die Pfeile. Den ausgefüllten Text kannst du einfach in ein Issue oder einen Chat kopieren.
